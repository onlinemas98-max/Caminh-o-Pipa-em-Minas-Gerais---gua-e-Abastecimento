CAMINHÃO-PIPA MG — PROJETO PARA GITHUB PAGES

1. Antes de publicar
- Substitua SEU-USUARIO em sitemap.xml, robots.txt e nas URLs canonical/og/canonical dos HTML pelo seu usuário real do GitHub.
- Se o nome do repositório for diferente de caminhao-pipa-mg, ajuste também o caminho base SITE nos canonical.
- A imagem da primeira dobra é carregada do endereço externo:
  https://i.postimg.cc/pXrBsHBs/Caminhao-pipa-azul-e-branco-siausij.webp
  Para maior controle, salve uma cópia em assets/img e atualize o src e og:image.

2. Publicação
- Extraia o ZIP.
- Envie o conteúdo da pasta caminhao-pipa-mg para a raiz do repositório GitHub Pages.
- Ative Pages nas configurações do repositório, usando a branch e pasta desejadas.
- Aguarde a publicação e teste os links no endereço final.

3. Formulário
O formulário da página inicial abre uma conversa do WhatsApp correspondente à cidade selecionada. Não existe envio para servidor nem gravação automática no painel.

4. Painel administrativo
O painel admin-leads.htm é apenas uma demonstração local. O código não exibe a senha no painel, mas uma senha implementada no JavaScript não oferece segurança real. O armazenamento local fica restrito ao navegador e não sincroniza entre usuários ou dispositivos. Para leads centralizados e autenticação real, será necessário backend/serviço de formulários com controle de acesso.

5. Contatos
Os números e links de WhatsApp foram configurados conforme a lista fornecida no pedido. Verifique-os antes de colocar o site no ar.
